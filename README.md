# 🌱 EcoFinds - Sustainable Second-Hand Marketplace

EcoFinds is a cross-platform application designed to promote sustainable consumption by making it easy and engaging for users to buy and sell second-hand products. Our mission is to empower communities to embrace a circular economy through a trusted and user-friendly marketplace.

## 🚀 Project Vision

EcoFinds seeks to revolutionize second-hand shopping by:

- Extending product lifecycles
- Reducing waste
- Making sustainability accessible and mainstream

We aim to be the **go-to destination** for conscious consumers looking for unique, affordable, and sustainable alternatives.

## 🎯 Hackathon Objective (Round 1)

Build a foundational prototype of EcoFinds with the following core features:

- 🔐 **User Authentication** (Email + Password)
- 👤 **Profile Creation & User Dashboard**
- 🛍️ **Product Listing Creation & Management (CRUD)**
- 🔎 **Product Browsing with Category Filtering and Keyword Search**
- 🖼️ **Product Detail View**
- 🛒 **Shopping Cart**
- 📦 **Previous Purchases View**

## 📱💻 Platform Compatibility

The application is designed to work seamlessly across **mobile** and **desktop** platforms, offering feature parity and a smooth user experience.

## 🧩 Key Features

| Feature | Description |
|--------|-------------|
| **User Authentication** | Secure login and registration using email and password |
| **User Dashboard** | Edit profile info and manage account settings |
| **Product Listings** | Create, view, update, and delete product listings |
| **Image Placeholder** | Add at least one image placeholder for each listing |
| **Category Filter** | Filter products by predefined categories |
| **Keyword Search** | Search listings by keywords in the title |
| **Product Detail View** | View full product details on a separate screen |
| **Cart** | View products added to the shopping cart |
| **Previous Purchases** | Track purchased items in a dedicated view |

## 🧪 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/ecofinds.git
   cd ecofinds

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm start
   ```

4. **Access the app:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
